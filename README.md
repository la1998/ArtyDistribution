## Plugins

### RollTracker

RollTracker is a private Truth or Dare `/random` helper for Final Fantasy XIV.

Features:
- Truth or Dare roll rounds
- `!truth`, `!dare`, `!help`, `!tod2`, and `!wifi` helpers
- Auto On/Off for housing
- Status Effects for Moodles, Honorific, and custom macros

Existing RollTracker users can keep the old repository URL for now, but new installs should use the repository URL above.
